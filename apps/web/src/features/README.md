# src/features

Thư mục `features` nên chứa các tính năng riêng biệt được tổ chức theo từng thư mục con. Mỗi thư mục con này cần mô phỏng cấu trúc của thư mục gốc `src` khi cần thiết.

Ví dụ:

- src/features/some-feature

  - some-feature/assets
  - some-feature/components
  - some-feature/hooks

- src/features/another-feature

  - another-feature/components
